# Social Post Feed Application

A full-stack web application built to create and view social feed posts. This is one of my first hands-on projects exploring full-stack web development.

---

## 🛠️ Tech Stack

* **Frontend:** React, React Router DOM, Axios, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

---

## ✨ Features

* Create new posts with text and image uploads
* Responsive post creation form
* Client-side form handling and navigation
* REST API endpoints for posting and fetching feeds
